\# Git basics



Git is a version control system that records the history of a project.



\## Commands



| Command | What it does |

|---|---|

| `git clone <url>` | Copies a GitHub repo to your PC |

| `git add <file>` | Stages a change for the next commit |

| `git commit -m "msg"` | Saves a snapshot of the staged changes |

| `git pull` | Downloads teammates' commits |

| `git push` | Sends your commits to GitHub |



\## Typical workflow

1\. `git pull` to get the latest version

2\. Edit files

3\. `git add` and `git commit`

4\. `git push`
